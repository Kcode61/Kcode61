## Sobre mim
Olá! Meu nome é **Kauan Moura Sobrinho** e sou desenvolvedor **Front-end** focado na criação de interfaces modernas, rápidas e bem estruturadas. Trabalho principalmente com **HTML, CSS e Tailwind CSS**, sempre buscando entregar projetos organizados, responsivos e com uma experiência visual agradável.

Meu objetivo é evoluir constantemente como desenvolvedor e criar soluções que realmente agreguem valor. Já desenvolvi diversos projetos — **landing pages, páginas institucionais, portfólios, formulários, sistemas fictícios e interfaces de produtos** — sempre com foco em clareza, performance e usabilidade.
